# Hidden History Engine — Full Replication Guide

> This file contains everything needed to rebuild the Hidden History Engine from scratch.  
> Another LLM or developer can use this as the sole reference.

---

## 1. Overview

The **Hidden History Engine** discovers obscure historical connections between recognizable people, places, and events by analyzing Wikipedia co-occurrence patterns. It generates daily "finding" reports, exports them to an Obsidian vault, and publishes an interactive HTML dashboard on GitHub Pages.

### What It Produces Daily
- 57–58 "findings" — each a 3-to-5-degree chain linking two recognizable entities
- Example: `Charles "Lucky" Luciano → Supreme Court → Egil Krogh → NATO → Vladimir Putin → The Supreme Court`
- Each finding includes: source trail, inference layer, open questions, and Wikipedia links
- Interactive HTML dashboard with starfield animation, tabbed views, modal detail popups

### Daily Runtime
- Phase 2: skipped (cached data), ~0 seconds
- Phase 3: ~310 seconds (graph build + BFS + novelty filter + dashboard)
- Git sync + Pages rebuild: ~30 seconds
- LLM API calls: 6 (batch novelty filter, 10 findings/call)

```python
    vol = config['external_volume']

def init_db():
    os.makedirs(os.path.dirname(DB_PATH), exist_ok=True)
    conn = sqlite3.connect(DB_PATH)
    conn.execute('PRAGMA journal_mode=WAL')
    conn.execute('''
        CREATE TABLE IF NOT EXISTS budget (
            date TEXT PRIMARY KEY,
            calls_used INTEGER DEFAULT 0
        )
    ''')
    conn.execute('''
        CREATE TABLE IF NOT EXISTS articles (
            id INTEGER PRIMARY KEY,
            title TEXT UNIQUE,
            text TEXT,
            links TEXT,
            fetched_at TEXT
        )
    ''')
    conn.execute('''
        CREATE TABLE IF NOT EXISTS wikidata_claims (
            id INTEGER PRIMARY KEY,
            entity_qid TEXT,
            property TEXT,
            value TEXT,
            value_label TEXT,
            source_url TEXT,
            fetched_at TEXT
        )
    ''')
    conn.execute('''
        CREATE TABLE IF NOT EXISTS findings (
            id INTEGER PRIMARY KEY,
            slug TEXT UNIQUE,
            title TEXT,
            teaser TEXT,
            scores_json TEXT,
            total_score REAL,
            degrees_of_separation INTEGER,
            entities TEXT,
            evidence_type TEXT,
            date_generated TEXT,
            brief_md TEXT,
            source_trail TEXT,
            open_questions TEXT
        )
    ''')
    conn.execute('''
        CREATE TABLE IF NOT EXISTS run_log (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            run_date TEXT,
            findings_count INTEGER,
            api_calls_used INTEGER,
            budget_remaining INTEGER,
            errors_count INTEGER,
            duration_seconds REAL
        )
    ''')
    conn.execute('''
        CREATE TABLE IF NOT EXISTS qid_labels (
            qid TEXT PRIMARY KEY,
            label TEXT,
            birth_date TEXT,
            death_date TEXT,
            entity_type TEXT,
            fetched_at TEXT
        )
    ''')
    try:
        conn.execute('ALTER TABLE wikidata_claims ADD COLUMN value_label TEXT')

        pass
    try:

        conn.execute('ALTER TABLE qid_labels ADD COLUMN death_date TEXT')

        pass
```

```python
import os
import json
import time
import random
from openai import OpenAI

class LLMClient:
    def __init__(self, config):
        self.config = config
        self.mock_mode = True
        api_key = os.environ.get('OPENROUTER_API_KEY')
        if not api_key:
            api_key = os.environ.get('NVIDIA_API_KEY')
            if api_key:
                self.client = OpenAI(api_key=api_key, base_url="https://integrate.api.nvidia.com/v1")
                self.mock_mode = False
                self.model_name = 'nvidia/llama-3.1-nemotron-ultra-253b-v1'
                return
        if api_key:
            self.client = OpenAI(api_key=api_key, base_url="https://openrouter.ai/api/v1")
            self.mock_mode = False
            self.model_name = config.get('llm_model', 'poolside/laguna-s-2.1:free')
            return
        else:
            self.client = None
            self.mock_mode = True
            self.model_name = 'mock'

    def call(self, prompt, system_prompt=None, max_retries=3, max_tokens=4096, temperature=0.7):
        if self.mock_mode:
            return self._mock_call(prompt)
        messages = []
        if system_prompt:
            messages.append({"role": "system", "content": system_prompt})
        messages.append({"role": "user", "content": prompt})
        for attempt in range(max_retries):
            try:
                response = self.client.chat.completions.create(
                    model=self.model_name,
                    messages=messages,
                    max_tokens=max_tokens,
                    temperature=temperature,
                    extra_headers={
                        "HTTP-Referer": "https://github.com/AjkurianAssistant",
                        "X-Title": "Hidden History Engine",
                    },
                )
                return response.choices[0].message.content.strip()
            except Exception as e:
                err_str = str(e)
                if '401' in err_str:
                    with open(self.config['errors_log'], 'a') as f:
                        f.write(f"[{time.strftime('%Y-%m-%d %H:%M:%S')}] LLM 401 Unauthorized\n")
                    return None
                elif '429' in err_str or '503' in err_str or '502' in err_str or '504' in err_str:
                    wait = 3 ** attempt + random.randint(0, 2)
                    time.sleep(wait)
                    continue
                else:
                    time.sleep(1)
                    continue
        with open(self.config['errors_log'], 'a') as f:
            f.write(f"[{time.strftime('%Y-%m-%d %H:%M:%S')}] LLM call failed after {max_retries} retries\n")
        return self._mock_call(prompt)

    def _mock_call(self, prompt):
        prompt_lower = prompt.lower()
        if 'commonly discussed' in prompt_lower:
            return json.dumps({"commonly_known": 'no', "reason": "Not commonly covered in popular history"})
        elif 'investigative' in prompt_lower and ('brief' in prompt_lower or 'format' in prompt_lower):
            return self._mock_brief(prompt)
        elif 'score' in prompt.lower() or 'rubric' in prompt.lower():
            return json.dumps({"novelty": 7, "evidence_strength": 6, "narrative_potential": 8})
        else:
            return "OK"

    def _mock_brief(self, prompt):
        path_line = ""
        for line in prompt.split('\n'):
            if line.startswith('Connection:'):
                path_line = line.replace('Connection: ', '')
                break
        if not path_line:
            path_line = prompt[:200]
        evidence_lines = []
        for line in prompt.split('\n'):
            if line.startswith('Hop '):
                evidence_lines.append(line)
        path_parts = [p.strip() for p in path_line.split(' → ')]
        degrees = len(path_parts) - 1
        if degrees == 3:
            title = f"Hidden Nexus: {path_parts[0]} → {path_parts[-1]} ({degrees}-degree Link)"
        elif degrees == 4:
            title = f"Shadow Chain: {path_parts[0]} → {path_parts[-1]} ({degrees}-degree Link)"
        else:
            title = f"Secret Loom: {path_parts[0]} → {path_parts[-1]} ({degrees}-degree Link)"
        teaser = f"A {degrees}-step chain linking {path_parts[0]} to {path_parts[-1]}"
        trail = ""
        for i in range(len(path_parts)-1):
            trail += f"Hop {i+1}: {path_parts[i]} → {path_parts[i+1]}\n"
            trail += f"  - Edge type: cooccurrence\n"
            trail += f"  - Source: Wikipedia co-occurrence\n"
            trail += f"  - URL: https://en.wikipedia.org/wiki/{path_parts[0].replace(' ', '_')}\n\n"
        if degrees == 3:
            inference = "This direct chain suggests a documented historical overlap between the two figures."
        elif degrees == 4:
            inference = "This longer chain requires a careful reading of intermediary relationships."
        else:
            inference = "This five-degree chain involves multiple inference leaps."
        brief = f"""# {title}
**Teaser:** {teaser}
## Hidden Chain
"""
        for i in range(len(path_parts)-1):
            brief += f"{i+1}. [[{path_parts[i]}]] —[**cooccurrence**]→ [[{path_parts[i+1]}]]\n\n"
        brief += f"""
## Source Trail
{trail}
## Inference Layer
{inference}
"""
        return brief

    def generate_open_questions(self, path_parts, degrees=None):
        if degrees is None:
            degrees = len(path_parts) - 1
        e1 = path_parts[0]
        eN = path_parts[-1]
        intermediates = path_parts[1:-1]
        question_pool = [
            f"Why is the connection between {e1} and {eN} absent from standard historical narratives?",
            f"What historical role has {intermediates[0] if intermediates else e1} played that mainstream accounts minimize or omit?",
            f"Are there other undiscovered chains linking {e1} to {eN} through different intermediary figures?",
            f"What documents or correspondence between these figures remain classified, lost, or uncatalogued?",
        ]
        if degrees <= 3:
            question_pool.append(f"Could the institutional positions held by {e1} and {eN} have created indirect contact never officially recorded?")
        else:
            question_pool.append(f"Do the {degrees} intermediaries in this chain share a common institutional background?")
        question_pool.append(f"Are there contemporaneous newspaper accounts or private letters that mention {e1} and {eN} in the same context?")
        question_pool.append(f"How do the financial or patronage networks connecting these figures compare to better-documented historical networks?")
        question_pool.append(f"Could any of the intermediary figures have served as unwitting conduits for broader historical forces?")
        num_to_pick = min(len(question_pool), 3 + (degrees - 2))
        selected = random.sample(question_pool, num_to_pick)
        return '\n'.join(f"- {q}" for q in selected) + "\n"

    def batch_call(self, prompts, system_prompt=None):
        results = []
        for prompt in prompts:
            result = self.call(prompt, system_prompt)
            results.append(result)
            time.sleep(1)
        return results

    def check_budget(self, conn):
        today = time.strftime('%Y-%m-%d')
        cur = conn.execute('SELECT calls_used FROM budget WHERE date=?', (today,))
        row = cur.fetchone()
        used = row[0] if row else 0
        return self.config['daily_budget'] - used

    def record_call(self, conn):
        today = time.strftime('%Y-%m-%d')
        conn.execute('''
            INSERT INTO budget (date, calls_used) VALUES (?, 1)
            ON CONFLICT(date) DO UPDATE SET calls_used = calls_used + 1
        ''', (today,))
        conn.commit()

    def record_call_safe(self, conn, success):
        if success:
            self.record_call(conn)

def create_llm_client(config):
    return LLMClient(config)
```

#### score_path function:
```python
def score_path(path, G, config):
    score = 0
    degrees = len(path) - 1
    score += max(10 - degrees * 2, 3)
    for i, node in enumerate(path):
        if i == 0 or i == len(path) - 1:
            score += recognizability_bonus(node, config)
        else:
            score += recognizability_bonus(node, config) // 2
    if temporal_overlap(path, G):
        score += 2
    for i in range(len(path) - 1):
        edge = G.get_edge_data(path[i], path[i+1])
        if edge and edge.get('type') != 'cooccurrence':
            score += 3
    edge_types = set()
    for i in range(len(path) - 1):
        edge = G.get_edge_data(path[i], path[i+1])
        if edge:
            edge_types.add(edge.get('type', 'cooccurrence'))
    if len(edge_types) > 1:
        score += 2
    for i in range(1, len(path) - 1):
        if not is_well_known(path[i]):
            score += 2
    domains = set()
    for node in path:
        domains.add(entity_domain(node))
    if len(domains) > 2:
        score += 2
    return score

def recognizability_bonus(entity, config):
    if is_well_known(entity):
        return 10
    # Check for partial matches
    name_lower = entity.lower()
    for kw in RECOGNIZABILITY_KEYWORDS:
        if kw in name_lower:
            return 5
    return 0

def temporal_overlap(path, G):
    """Check if all entities in path have overlapping lifetimes."""
    dates = []
    for node in path:
        if node in G.nodes:
            birth = G.nodes[node].get('birth_date')
            death = G.nodes[node].get('death_date')
            if birth and death:
                try:
                    b = int(re.search(r'\d{4}', birth).group())
                    d = int(re.search(r'\d{4}', death).group())
                    dates.append((b, d))
                except:
                    pass
    if len(dates) < 2:
        return False
    min_death = min(d for _, d in dates)
    max_birth = max(b for b, _ in dates)
    return min_death >= max_birth

def entity_domain(entity):
    """Categorize entity into broad domain."""
    name = entity.lower()
    if any(k in name for k in ['war', 'revolution', 'civil', 'depression', 'crisis', 'scandal']):
        return 'event'
    if any(k in name for k in ['court', 'senate', 'house', 'congress', 'president', 'government']):
        return 'politics'
    if any(k in name for k in ['cia', 'fbi', 'kgb', 'intelligence', 'agency']):
        return 'intelligence'
    if any(k in name for k in ['mafia', 'mob', 'crime', 'gangster', 'luciano', 'capone']):
        return 'crime'
    if any(k in name for k in ['church', 'catholic', 'synagogue', 'mosque', 'vatican']):
        return 'religion'
    if any(k in name for k in ['press', 'tribune', 'journal', 'magazine', 'times', 'post']):
        return 'media'
    if any(k in name for k in ['university', 'college', 'harvard', 'yale', 'princeton']):
        return 'education'
    return 'other'
```

## 10. Key Algorithms Explained

### A. Entity Canonicalization
Maps NER fragments and Wikipedia article titles to Wikidata QIDs. Uses:
- Direct lookup in `qid_labels` table
- Abbreviation matching: "FBI" → "Federal Bureau of Investigation"
- Fuzzy matching: `Levenshtein.distance(entity, qid_label) < 3`

### B. Recognizability Scoring
Entities that appear in `RECOGNIZABILITY_KEYWORDS` (100+ terms) or in the `is_well_known()` function get scoring bonuses. Endpoints in a path get +10, intermediates get +5.

### C. Temporal Overlap
Entities with Wikidata birth/death dates get a +2 bonus if the chain spans overlapping lifetimes. E.g., if Schuyler Colfax (1832–1912) connects to someone born in 1880, that's a temporal match.

### D. Structured Edge Bonus
When two entities have a Wikidata property relationship (e.g., P108 "employer", P463 "member of"), the edge gets +3 bonus and is labeled with the property type.

### E. Cross-Domain Bonus
If a 5-degree path spans >2 domains (e.g., politics → media → crime → intelligence → education), it gets +2 for narrative potential.

### F. Novelty Filtering
Batches 10 path candidates into a single LLM call:
```
For each path, answer: Is this connection commonly discussed in popular history,
educational courses, or mainstream media? Answer YES or NO only.

1. Kennedy → Supreme Court → Watergate → Nixon → Vietnam War
   ...

2. Mafia → Luciano → NBC → Stanford White → ...
   ...

[10 paths total]
```
Only paths where the LLM says "NO" (not commonly known) proceed to brief generation.

## 14. Improvement Opportunities

### A. Expand Wikidata Coverage (phase2_ingest.py:435-527)
Currently only **8 structured edges** are found because the seed QID list is too small. The `resolve_wikipedia_to_qid()` function correctly resolves titles to QIDs via the Wikipedia REST API, but the `SEED_QIDS` dictionary is incomplete. Fix: expand SEED_QIDS to include 50+ entities, or automatically resolve all entity titles to QIDs.

### B. Improve QID-to-Node Mapping (phase3_analyze.py)
Only **96/6983 nodes** get QIDs. The `entity_canonicalization` step does fuzzy matching but misses many entities. Fix: after Phase 2, add a batch QID resolution step that resolves all entity names from the `articles` table to QIDs via the Wikipedia REST API.

### C. Increase Temporal Coverage (phase3_analyze.py)
Only **95/6983 nodes** have temporal data. The `qid_labels` table has 143 entries with birth/death dates, but these aren't being matched to the right nodes. Fix: improve the QID matching in `build_graph()` to use the `value_label` column from `wikidata_claims` for entity resolution.

### D. Batch Novelty Filter (phase3_analyze.py:1090-1098)
Currently batches 10 findings/call (6 calls for 58 findings). Could increase to 20/call (3 calls) but the LLM accuracy degrades with too many items. Alternative: use LLM structured output with JSON schema instead of free-text YES/NO.

### E. Entity Descriptions (generate_dashboard.py)
The `ENTITY_DESCRIPTIONS` dictionary has ~150 entries. Many entities get generic fallbacks. Fix: either (a) expand to 500+ entries, or (b) auto-fetch Wikidata descriptions via the REST API and embed them in the HTML.

### F. Hub Node Threshold (phase3_analyze.py)
Currently uses `deg >= 483` as the hub threshold. This varies between runs (465-483). Fix: use a percentile-based threshold (e.g., top 2% of nodes by degree).

### G. Candidate Selection (phase3_analyze.py)
The 500 endpoint pairs are selected from ~4000 notable entities. Currently uses `random.sample` — could use a more targeted approach: prefer pairs that span different domains (politics to crime, etc.) and have temporal overlap.

### H. Scoring Weights (phase3_analyze.py:score_path)
Current weights:
- Base: 3-10 points
- Recognizability: 5-10 per entity
- Temporal: +2
- Structured edge: +3
- Cross-domain: +2
- Obscurity: +2

These are tuned for ~20-26 point scores. Could adjust for different sensitivity.
